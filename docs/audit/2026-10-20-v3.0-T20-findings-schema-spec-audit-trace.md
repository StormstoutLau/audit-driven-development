### 2.3 低效/反模式自查

| 检查项 | 结论 |
|---|---|
| 函数内 `import re` | 校验器在模块级 `import re` + 预编译 `pattern` 缓存 ✅ |
| O(n²) 查找 | `$ref` 解析 O(1)（定义名索引）；`rules_index` 沿用既有 O(1) ✅ |
| 重复计算 | schema 只加载一次；`_extract_findings` 单遍 ✅ |
| 死参数/死字段 | `--json` / `--quiet` 均需被 `main()` 消费（Step 10 A 组断言） |
| 静默忽略 | 不支持关键字 ⇒ exit 2（T2_10 固化） ✅ |
