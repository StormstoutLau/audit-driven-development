## 4. Phase 8 修复内容

### 4.1 Bug B1: Joern CPG 导入节点命名不一致 (已在上一轮修复)

**根因**: `joern_cpg.py` 的 `_gen_import_script()` 中, `imp.file.head.name` 带 `.py` 后缀而 `imp.importedEntity` 不带, 导致 DFS 图遍历断裂。

**修复**: 标准化节点名称, 移除 `.py` 后缀。

### 4.2 Bug B2: dead_code/import_related 降级逻辑错误 (已在上一轮修复)

**根因**: `verify_findings.py` 中 dead_code 和 import_related findings 的降级逻辑不正确。

**修复**: 
- dead_code: 始终运行 Tier 2 双重验证, Joern True + Tier 2 True → 保留 Joern, 不一致 → Tier 2 优先
- import_related: Joern verified=False → 降级到 Tier 2

### 4.3 Bug B3: classify_claim 误分类 import exists 声明 (本轮修复)

**根因**: `IMPORT_PATTERNS` 使用 `\bimport\b` 匹配所有含 "import" 的 claim, 导致 "import statement exists" (存在性声明) 被误分类为 `import_related` (循环依赖检测), 触发不相关的验证逻辑。

**修复**: 
- `IMPORT_PATTERNS` 精细化为仅匹配循环依赖相关模式 (`circular dep`, `import cycle`, `mutual import` 等)
- `DEAD_CODE_PATTERNS` 新增 `\bimport\b.*\b(?:not|never)\s+used\b` 模式, 将 "import X not used" 正确分类为 dead_code

**效果**: ITD-R1 (real_import_exists) 从 FP (误删) 修复为 TN (正确保留), Precision 从 81.2% 恢复到 100.0%。

### 4.4 Bug B4: Ground Truth 标注错误 (本轮修复)

**根因**: `ground_truth.json` 中 SA-1 和 SA-4 被错误标注为 `real_bug`:
- SA-1: claim 说 "dead code after return in visit_FunctionDef", 但 `visit_FunctionDef` 没有 return 语句 → 实际是 hallucination
- SA-4: claim 说 "dead code after raise in visit_Raise alias", 但 line 171 是别名赋值 `visit_Raise = visit_Return` → 实际是 hallucination

**修复**: 更正 ground_truth 为 hallucination 类型, 同步更新 analyze.py。

### 4.5 改进: hallucination 条目保留 tier 信息 (本轮修复)

**根因**: hallucination 条目仅保留 `id/claim/file/line/severity/reason`, 丢失 L4 checks 和 tier 信息, 导致 benchmark tier 分布统计不准确。

**修复**: 新增 `l4` 和 `best_tier` 字段, benchmark 脚本 `extract_tier_info` 同步更新。

## 5. Tier 1 (Joern CPG) 分析

**现象**: tier1=0, 但 `joern_cpg.is_available()` 返回 True。

**原因**: Phase 8 设计预期, 非故障:
- **dead_code**: Joern 运行 method-level 分析, 但 claim 通常是 statement-level (return 后不可达)。Phase 8 策略: 始终运行 Tier 2 双重验证, Tier 2 (statement-level) 结果优先。当 Tier 2 有确定结论时, 存储的是 Tier 2 结果 (tier=2)。
- **import_related**: Joern `verified=False` 时降级到 Tier 2 (pysrc2cpg Python 支持不完善)。只有 `verified=True` (确认循环) 才保留 Tier 1 结果。

**结论**: Joern 在运行, 但在当前测试集中所有 case 都被 Tier 2 覆盖。这是 statement-level claim 与 method-level Joern 分析之间语义粒度差异的预期行为。
