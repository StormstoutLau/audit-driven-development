## 11. 已知局限（诚实披露）

1. **语料休眠**：882 条语料对 `category`/`analysis_kind` 零触发 ⇒ 能力覆盖由 golden case + 转换器 fixture 承担；
2. **Semgrep CE `dataflow_trace` 无官方保证**（X-3 `[unverified]`）⇒ 分支以构造 JSON 验证，真实 CE 输出留作 P1 证据；
3. **CodeQL 端点次序不得假设**：本步只写 `analysis_kind`，不解析 `codeFlows` 路径（N-5）；T0.7 的端点校验要求移交 Phase 2/T12；
4. **`SastFinding.evidence` 开放**：工具溯源键不做白名单（顶层 `additionalProperties:false` 仍严格）；
5. **转换器 `line_start` 可能为 0**（Semgrep/CodeQL 缺行号时）⇒ 该产物会被 `sast` schema 判违规（`minimum:1`）；这是**有意的严格性**，属于工具产物质量问题而非 schema 缺陷。
