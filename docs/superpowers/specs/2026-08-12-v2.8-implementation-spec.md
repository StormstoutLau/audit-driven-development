## 0. 全局工程约束

### 0.1 Python 版本与依赖

| 项 | 要求 | 说明 |
|---|---|---|
| Python 版本 | ≥ 3.9 | f-string/Path/typing 兼容；不使用 3.10+ 的 `match/case` 和 `|` 类型联合 |
| 标准库优先 | ✅ | 仅在必要时引入第三方库 (T4 SARIF 解析可选用 `sarif-tools`，但有纯 stdlib fallback) |
| 禁止新依赖 | pyyaml / requests / sarif-tools | v2.8 不引入新 runtime 依赖；GitHub Actions 中使用 `actions/setup-python@v5` + stdlib |
| 类型注解 | 可选 | 函数签名添加类型注解，但不用 `typing.TypedDict` (3.8 兼容) |

### 0.2 文件 I/O 性能规范

| 场景 | 规范 | 反模式 |
|---|---|---|
| JSON 读写 | `json.load(f)` / `json.dump(obj, f, indent=2, ensure_ascii=False)` | ❌ `json.loads(Path(p).read_text())` 对 >50MB 文件 (内存峰值) |
| 大文件流式 | csv 模块 `DictReader` (现有 bigvul 转换器模式) | ❌ `pandas.read_csv()` (引入 30MB 依赖) |
| 文件编码 | 统一 `encoding="utf-8"` | ❌ 默认编码 (Windows GBK) |
| 路径拼接 | `Path(a) / b` | ❌ `os.path.join` (混用风格) |
| 文件存在检查 | `Path.exists()` + 一次性 read | ❌ 多次 `open()` 同一文件 |

### 0.3 向后兼容硬规则

1. **threshold=None 必须等价于 v2.7 行为** — 所有新参数默认值保证 v2.7 调用方零改动
2. **finding schema 字段只增不删** — 新增 `evidence.cwe_rank` 等字段，不修改既有字段语义
3. **CLI 参数新增必须带默认值** — `--batch-size` 默认 50，`--history-threshold` 默认 None
4. **import 兼容** — 新增模块 `cwe_rules.py` 必须支持 `from cwe_rules import enrich_finding_with_cwe` 和 `python -m cwe_rules` 两种调用

### 0.4 低效操作清单 (禁止)

| 反模式 | 修正 | 原因 |
|---|---|---|
| `for f in findings: json.loads(json.dumps(f))` 深拷贝 | `copy.deepcopy(f)` 或 `{**f, "evidence": {**f["evidence"]}}` | json 往返比 deepcopy 慢 5-10x |
| `re.findall(r'.+', text)` 分行 | `text.splitlines()` | regex 分行有回溯开销 |
| `list(filter(lambda x: x.sev == "P0", findings))` | `[f for f in findings if f.get("severity") == "P0"]` | 列表推导比 filter+lambda 快 20% |
| 多次 `Path.exists()` 同一文件 | 缓存到变量 | syscall 开销 |
| `subprocess.run` 不带 `timeout` | 必须设 `timeout=300` (网络) / `timeout=60` (本地 git) | 防止网络挂起 |
| `time.sleep(60)` 硬编码 | `args.batch_delay` 参数化 | 调试时改为 0 |
| 在循环内 `open()` 同一输出文件 | 循环外打开或收集后一次性 write | I/O 开销 |

### 1.2 算法实现规范

#### 1.2.1 `_threshold_to_min_keywords()` (新增)

```python
def _threshold_to_min_keywords(threshold):
    """v2.8: 将 RL-adjusted threshold 映射到 L3 最小 keyword 匹配数.

    Args:
        threshold: float ∈ [0.55, 0.85] 或 None

    Returns:
        int: min_keywords (1 或 2)

    Mapping:
        None          → 1 (默认, 向后兼容)
        [0.55, 0.75)  → 1 (宽松, improving trend)
        [0.75, 0.85]  → 2 (严格, declining trend)
    """
    if threshold is None:
        return 1
    if threshold >= 0.75:
        return 2
    return 1
```

**性能**: O(1)，两次比较，无内存分配。

#### 1.2.2 `verify_l3()` 修改 (L198-L222)

当前代码 (v2.7):
```python
def verify_l3(lines, line_num, keywords):
    # 先在 target_line 精确匹配，再在 ±20 行邻近窗口内匹配
    # confirmed = True 当且仅当至少 1 个 keyword 在窗口内匹配
```

修改为:
```python
def verify_l3(lines, line_num, keywords, min_keywords=1):
    """Level 3: Keyword/pattern match in source context (±20 lines).

    v2.8: 新增 min_keywords 参数, 控制 confirmed 所需的最小匹配 keyword 数.
        min_keywords=1 (默认): 至少 1 个 keyword 匹配 (v2.7 行为)
        min_keywords=2: 至少 2 个不同 keyword 匹配 (严格模式)

    Args:
        lines: list of source code lines (from L2).
        line_num: 1-indexed line number to verify.
        keywords: list of keyword strings to search.
        min_keywords: minimum number of distinct keywords that must match.

    Returns:
        dict with keys: level, confirmed, matched_keywords (list), matched_lines (list).
        ⚠️ 兼容字段: confirmed=True 时同时返回 matched_keyword (单数, str) 和
        matched_line (单数, int), 取 list[0], 供下游 (如 test_e2e_v24_integration.py:296)
        读取. v2.7 代码读取 l3.get('matched_keyword', '') 不会 KeyError.
    """
    if not keywords:
        return {"level": 2, "confirmed": False, "reason": "no_keywords_to_match"}

    matched_keywords = []
    matched_lines = []

    # 收集 target_line 上的所有匹配 (不是找到第一个就返回)
    target_lower = lines[line_num - 1].lower()
    for kw in keywords:
        if kw.lower() in target_lower:
            if kw not in matched_keywords:
                matched_keywords.append(kw)
                matched_lines.append(line_num)

    # 若 target_line 已满足 min_keywords, 提前返回 (短路优化)
    if len(matched_keywords) >= min_keywords:
        return {"level": 3, "confirmed": True,
                "matched_keywords": matched_keywords[:min_keywords],
                "matched_lines": matched_lines[:min_keywords],
                # ⚠️ 兼容字段 (v2.7 下游读取 matched_keyword/matched_line 单数)
                "matched_keyword": matched_keywords[0],
                "matched_line": matched_lines[0]}

    # 邻近窗口 ±20 行扫描
    for offset in range(1, 21):
        for direction in (-1, 1):
            check_line = line_num + direction * offset
            if 1 <= check_line <= len(lines):
                check_lower = lines[check_line - 1].lower()
                for kw in keywords:
                    if kw.lower() in check_lower and kw not in matched_keywords:
                        matched_keywords.append(kw)
                        matched_lines.append(check_line)
                        # 满足 min_keywords 时立即返回 (短路)
                        if len(matched_keywords) >= min_keywords:
                            return {"level": 3, "confirmed": True,
                                    "matched_keywords": matched_keywords,
                                    "matched_lines": matched_lines,
                                    # ⚠️ 兼容字段
                                    "matched_keyword": matched_keywords[0],
                                    "matched_line": matched_lines[0]}

    # 未达到 min_keywords
    if matched_keywords:  # 有匹配但不足
        return {"level": 3, "confirmed": False,
                "reason": f"only {len(matched_keywords)} keywords matched, need {min_keywords}",
                "matched_keywords": matched_keywords,
                "matched_lines": matched_lines}
    return {"level": 2, "confirmed": False,
            "reason": "no keyword match within ±20 lines",
            "keywords_searched": keywords}
```

**算法性能分析**:
- 时间复杂度: O(20 × 2 × |keywords|) = O(40K)，其中 K = |keywords| ≤ 5 (extract_keywords 截断到 5)
- 最坏情况: 40 × 5 = 200 次字符串 `in` 操作，单次 < 1μs，总计 < 0.2ms
- **短路优化**: 满足 min_keywords 时立即返回，平均 case 远低于最坏
- 内存: matched_keywords 最多 5 个字符串，可忽略

**向后兼容性**:
- `min_keywords=1` 默认值 → 行为与 v2.7 等价 (至少 1 个 keyword 匹配即 confirmed)
- 返回值新增 `matched_keywords` (list) 和 `matched_lines` (list)
- ⚠️ **兼容字段已内联到所有 confirmed=True 的 return 点**: `matched_keyword` (单数 str) 和 `matched_line` (单数 int), 取 list[0]
- **下游影响验证**: `test_e2e_v24_integration.py:296` 读取 `l3.get('matched_keyword', '')`, v2.8 保留该字段 → 不会 KeyError, 不会丢失信息

**⚠️ L3 `level` 字段语义变化** (v2.8 vs v2.7):
- v2.7: L3 失败 (无 keyword 匹配) 返回 `level=2, confirmed=False`
- v2.8: L3 有匹配但不足 min_keywords 时返回 `level=3, confirmed=False` (新增语义: L3 执行了但未达阈值)
- v2.8: L3 完全无匹配时仍返回 `level=2, confirmed=False` (与 v2.7 一致)
- **影响**: 下游代码 (`verify_single_finding`) 只读 `l3["confirmed"]`, 不依赖 `l3["level"]` 区分失败原因 → 不会 break

### 2.2 字段映射实现规范

#### 2.2.1 数组类型处理 (H3 幻觉修正点)

```python
def _extract_cwe(metadata):
    """从 Semgrep metadata.cwe 数组提取 CWE 标识.

    Args:
        metadata: dict, Semgrep result 的 extra.metadata

    Returns:
        str: CWE 标识 (如 "CWE-78") 或空字符串

    Note:
        Semgrep 的 cwe 字段是数组类型, 元素格式如:
        "CWE-78: Improper Neutralization of ... ('OS Command Injection')"
        需要提取 "CWE-78" 部分.
    """
    cwe_list = metadata.get("cwe", [])
    if not cwe_list or not isinstance(cwe_list, list):
        return ""
    # 取第一个元素, 用正则提取 CWE-XX
    match = _CWE_RE.search(cwe_list[0])
    return match.group(0) if match else ""


def _extract_owasp(metadata):
    """从 Semgrep metadata.owasp 数组提取 OWASP 分类."""
    owasp_list = metadata.get("owasp", [])
    if not owasp_list or not isinstance(owasp_list, list):
        return ""
    return owasp_list[0] if owasp_list else ""
```

**性能**: 正则 `CWE-\d+` 在 < 100 字符字符串上 < 1μs。

```python
def convert_semgrep_result(result, idx):
    """转换单个 Semgrep result 到 ADD finding."""
    check_id = result.get("check_id", f"unknown-{idx}")
    path = result.get("path", "")
    start = result.get("start", {})
    line = start.get("line", 0)
    extra = result.get("extra", {})

    severity_str = extra.get("severity", "INFO")
    metadata = extra.get("metadata", {})

    cwe = _extract_cwe(metadata)
    owasp = _extract_owasp(metadata)

    finding = {
        "id": f"SG-{idx:04d}",  # 前缀 SG- + 4 位序号
        "severity": SEVERITY_MAP.get(severity_str, "P2"),

            path=path, line=line),

            "file": path,
            "line_start": line,
            "cwe": cwe,
            "owasp": owasp,
            "rule_id": check_id,
            "source": "semgrep",
        },
        "l4_eligible": True,
        "dimension": "security",
    }
```

### 3.1 SARIF 解析规范

```python
# 模块级常量 (§0.4 性能规范: 预编译正则 + 模块级 import)
import re
_CWE_TAG_RE = re.compile(r"cwe-(\d+)", re.IGNORECASE)

LEVEL_MAP = {"error": "P0", "warning": "P1", "note": "P2"}


def parse_sarif(sarif_path: Path) -> list:
    """解析 SARIF 文件, 返回 (results, rules_index) 元组.

    Args:
        sarif_path: SARIF JSON 文件路径

    Returns:
        tuple: (results list, rules_dict by ruleId)

    Note:
        SARIF 结构: runs[0].results + runs[0].tool.driver.rules
        rules_index 预构建为 {ruleId: rule_dict} 避免 O(n²) 查找
    """
    data = json.loads(sarif_path.read_text(encoding="utf-8"))
    runs = data.get("runs", [])
    if not runs:
        return [], {}

    run = runs[0]
    results = run.get("results", [])

    # 预构建 rules 索引 (O(n) 一次, 避免 result × rules O(n²) 查找)
    rules_list = run.get("tool", {}).get("driver", {}).get("rules", [])
    rules_index = {r.get("id", ""): r for r in rules_list}

    return results, rules_index
```

**性能**: rules_index 预构建避免 O(n²)，对 1000 results + 100 rules 从 100,000 次查找降到 1,000 次。

### 3.2 CWE Tags 解析 (H4 修正点)

```python
def _extract_cwe_from_tags(rule):
    """从 CodeQL rule 的 properties.tags 提取 CWE 标识.

    Args:
        rule: dict, SARIF rule 对象

    Returns:
        str: CWE 标识 (如 "CWE-78") 或空字符串

    Note:
        CodeQL 约定在 tags 中输出 "external/cwe/cwe-78" 等标签.
        SARIF 规范不强制要求 cwe 标签存在, 因此缺失时返回空字符串.
    """
    tags = rule.get("properties", {}).get("tags", [])
    if not tags or not isinstance(tags, list):
        return ""
    for tag in tags:
        # 匹配 "external/cwe/cwe-78" 或 "cwe-78" 等格式
        match = _CWE_TAG_RE.search(tag)
        if match:
            return f"CWE-{match.group(1)}"
    return ""
```

```python
    level = result.get("level", "note")

            "cwe": cwe,
            "rule_id": rule_id,
            "source": "codeql",
        },
        "l4_eligible": True,
```

```python
def enrich_finding_with_cwe(finding):
    """如果 finding 的 claim/evidence 含 CWE-XX, 添加 cwe_rank 和 cwe_category.

    Args:
        finding: dict, ADD finding

    Returns:
        dict: 增强后的 finding (原 finding 被 in-place 修改)

    Note:
        - 无 CWE 时 finding 不变 (不崩溃)
        - CWE 不在 Top 25 时仅添加 cwe_rank=None
    """
    evidence = finding.get("evidence", {})
    cwe_id = evidence.get("cwe", "")

    # 从 claim 中提取 CWE (如果 evidence.cwe 为空)
    if not cwe_id:
        claim = finding.get("claim", "")
        match = re.search(r"CWE-\d+", claim)
        cwe_id = match.group(0) if match else ""

    if cwe_id and cwe_id in CWE_TOP_25_2023:
        info = CWE_TOP_25_2023[cwe_id]
        evidence["cwe_rank"] = info["rank"]
        evidence["cwe_category"] = info["category"]
        evidence["cwe_name"] = info["name"]
        if not evidence.get("cwe"):
            evidence["cwe"] = cwe_id
        finding["evidence"] = evidence

    return finding


def classify_cwe_severity(finding):
    """根据 CWE category 调整 severity.

    memory/injection 类 → P0 (高风险)
    其他类 → 保持原 severity
    """
    category = finding.get("evidence", {}).get("cwe_category", "")
    if category in ("memory", "injection"):
        finding["severity"] = "P0"
    return finding


def get_cwe_claim_keywords(cwe_id):
    """返回该 CWE 的典型关键词列表 (用于 L3 验证增强).

    Args:
        cwe_id: str, 如 "CWE-78"

    Returns:
        list: 关键词列表 (如 ["inject", "sql", "command", ...])
        若 CWE 不在 Top 25, 返回空列表
    """
    if cwe_id not in CWE_TOP_25_2023:
        return []
    category = CWE_TOP_25_2023[cwe_id]["category"]
    return CWE_KEYWORDS.get(category, [])
```

```python
def load_progress(progress_path: Path) -> dict:
    """加载进度文件, 返回 {commit_hash: status} dict."""
    if not progress_path.exists():
        return {}
    try:
        data = json.loads(progress_path.read_text(encoding="utf-8"))
        return {item["commit"]: item["status"] for item in data.get("downloaded", [])}
    except (json.JSONDecodeError, KeyError):
        return {}


def save_progress(progress_path: Path, progress: dict):
    """保存进度到文件 (原子写入)."""
    progress_path.parent.mkdir(parents=True, exist_ok=True)
    # 原子写入: 先写 .tmp 再 rename (避免写入中断导致文件损坏)
    tmp_path = progress_path.with_suffix(".tmp")
    data = {"downloaded": [{"commit": k, "status": v} for k, v in progress.items()]}
    tmp_path.write_text(json.dumps(data, indent=2, ensure_ascii=False), encoding="utf-8")
    tmp_path.replace(progress_path)  # 原子 rename
```

```python
    last_error = ""
    for attempt in range(max_retry):
        ok, err = fetch_func(commit_hash)
        if ok:
            return True, ""
        last_error = err
        if attempt < max_retry - 1:
            time.sleep(retry_delay)
    return False, last_error


def batch_download(findings, batch_size=50, batch_delay=60, ...):
    """分批下载, 批间延迟."""
    total = len(findings)
    batches = [findings[i:i + batch_size] for i in range(0, total, batch_size)]

    for batch_idx, batch in enumerate(batches):
        print(f"Batch {batch_idx + 1}/{len(batches)}: "
              f"{len(batch)} commits")
        for f in batch:
            # ... download_with_retry ...
            pass
        if batch_idx < len(batches) - 1:
            print(f"  Batch delay: {batch_delay}s...")
            time.sleep(batch_delay)
```
