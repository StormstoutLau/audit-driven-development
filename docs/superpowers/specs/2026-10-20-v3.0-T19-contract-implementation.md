## 2. `scripts/contract_graph.py` —— 函数签名与算法

```python
"""v3.0 T19: 跨模块契约确定性验证 (Tier 2, 纯 stdlib)。

复用 ast_cfg.build_import_graph / _parse_modules_from_claim，不引入任何新依赖。
三态: True=claim 断言成立 / False=声明合法且图完整但断言不成立 / None=无裁决(调用方不写 check)。
"""

CONTRACT_DECL_PATHS = ("docs/audit/guards.yml", "docs/audit/guards.project.yml", "docs/audit/guards.common.yml")
_GRAPH_CACHE = {}          # {(abs_root): (mtime_sig, graph)}
_GRAPH_CACHE_MAX = 8
```

| 函数 | 签名 | 职责 | 算法要点 | 复杂度 |
|---|---|---|---|---|
| `_mtime_sig` | `(root) -> float \| None` | 图缓存失效签名 | `max(os.path.getmtime(f) for f in Path(root).rglob("*.py") if not {"__pycache__", ".venv", ".git"} & set(f.parts))`；异常/空 ⇒ `None`（**G-7**: 必须排除 `.git`，防仓库根递归遍历 benchmark 克隆） | O(F) |
| `_build_graph` | `(root) -> dict \| None` | 取图（带缓存与**哨兵**） | ① 计算 `sig`；② **缓存命中条件 = 键存在 且 缓存 sig == 本次 sig**（**G-3**），命中即返回；③ `ast_cfg.build_import_graph(root)`；④ **哨兵**：`len(graph) > 1 and sum(len(v) for v in graph.values()) == 0` ⇒ 返回 `None`（记 `graph_incomplete`）；⑤ 写缓存（超 `_GRAPH_CACHE_MAX` 则清空最早键） | O(F·S) 首次 / O(F) 命中 |
| `_has_dynamic_import_at` | `(root, module) -> bool` | 动态 import 探测 | **模块名 → 文件映射（G-4）**：`root/module.replace(".", os.sep) + ".py"`，回退 `root/.../__init__.py`；两者皆不存在 ⇒ `False`。对命中文件 `ast.walk` 查 `Call(func=Name("__import__") \| Attribute(attr="import_module"))` | O(S) |
| `layer_of` | `(module, layers) -> str \| None` | 层↔模块前缀映射 | 取**最长匹配**前缀的层（`module == L` 或 `module.startswith(L + ".")`）；未命中 ⇒ `None` | O(L) |
| `find_path` | `(graph, src, dst) -> list[str] \| None` | 模块图可达性 **+ 路径证据**（**G-2**：替代 v1.0 的 `path_exists`） | **迭代式 BFS + `visited` 集**（含环安全）+ **前驱回溯**返回实际路径；`src == dst` ⇒ 先查自环 `src in graph.get(src, [])`；图/端点缺失 ⇒ `None` | O(V+E) |
| `_load_yaml` | `(path) -> dict \| None` | 可选 YAML 解析 | `try: import yaml` 失败 ⇒ `None`；`yaml.safe_load` 异常 ⇒ `None`（**不抛**）；顶层非 dict ⇒ `None` | O(1) |
| `load_contract_declarations` | `(repo_root, guards_path=None) -> list[dict] \| None` | 探测 + 解析 + 校验 | ① `guards_path` 优先，否则按 `CONTRACT_DECL_PATHS` 顺序探测；② 全部缺失 ⇒ `None`；③ 逐条取 `guards[]` 中 `contract` 非空的项；无 ⇒ `None`；④ 每条经 `_validate_layers`；**非法者被剔除**（不 abort 全部） | O(G) |
| `_validate_layers` | `(contract) -> bool` | 声明合法性 | 要求：`kind == "layers"` ∧ `layers` 为 list ∧ `len >= 2` ∧ 全为 str ∧ **无重复**；`allow` 若存在须为 `[[str,str], ...]` | O(L) |
| `_parse_direction` | `(claim, modules) -> tuple[str,str] \| None` | claim → (src, dst) | 依 §2.2 方向判据（见 §2.1）；`between/among/自环` ⇒ `None` | O(1) |
| `evaluate_contract` | `(graph, contract, src, dst) -> bool \| None` | 三态求值 | 见 §2.2 判定表 | O(V+E) |
| `verify_contract` | `(repo_root, claim, evidence=None, guards_path=None, language="python") -> dict \| None` | **对外唯一入口** | 见 §2.3 流程 | 见上 |

### 2.1 `_parse_direction` 判据（对应 design §2.2）

| claim 形态 | 正则 | 返回 |
|---|---|---|
| `X imports Y` | `([\w\.]+)\s+imports\s+([\w\.]+)`（复用 `ast_cfg` 既有模式族，但**取前两项为方向**） | `(X, Y)` |
| `X imports itself` | 同上 | **`None`**（H4：层次语义不适用） |
| `... between X and Y` / `among ...` | — | **`None`**（方向不可判定） |
| 其余 / 模块数 < 2 | — | **`None`** |

> **实现细节**：`_parse_modules_from_claim` 返回**有序列表**；仅当**首个被识别形态是 `imports` 链**时才有方向语义。实现时**先用 `imports` 正则单独匹配**，命中才产出 `(X, Y)`；否则一律 `None`（**不得用 `between` 的顺序猜方向**）。

### 2.2 `evaluate_contract` 三态判定表

前置：`layers` 合法；`layer_of(src)` 与 `layer_of(dst)` 均**非 None**（否则调用方已返回 `None`）；`src`、`dst` 均在图中。

> **索引语义（必读，Step 9 实施期发现的写反修正）**: `layers[0]` 是**最高层**、`layers[-1]` 是**最低层**（D-T19-2「顺序 = 高→低」）。
> ⇒ `idx(src) < idx(dst)` 表示 **src 更高** ⇒ **允许方向**；`idx(src) > idx(dst)` 表示 **src 更低** ⇒ **被禁方向**。
> （v1.0 曾把这两者写反，导致 AC-6 与判定表自相矛盾；本表已按 AC 的文字口径校正。）

| # | 条件 | 返回 |
|---|---|---|
| 1 | `src` 与 `dst` 命中**同一层** | **`None`**（层内依赖不在分层语义内） |
| 2 | `idx(src) > idx(dst)`（src 更低 ⇒ **被禁方向**）∧ `find_path(graph, src, dst)` 非 `None` ∧ `(src,dst) ∉ allow` | **`True`**（断言成立）← AC-6 |
| 3 | 同 2 但 `(src,dst) ∈ allow` | **`False`**（反向例外 ⇒ 断言不成立）← AC-9 |
| 4 | `idx(src) > idx(dst)`（被禁方向）∧ **无路径** | **`False`**（断言不成立）← AC-8b |
| 5 | `idx(src) < idx(dst)`（src 更高 ⇒ **允许方向**） | **`False`**（允许方向不可能构成层违规 ⇒ 断言不成立）← AC-7 |
| 6 | `idx(src) == idx(dst)` | 见 #1 ⇒ `None` |

> **`verified` 语义**：`True` = 「**claim 断言成立**」（H2 修正后的统一口径）。

> **动态 import 的精确作用域（Step 9 实施期细化，推翻 v1.0 的"无条件跳过"）**：
> v1.0 规定「涉事模块含动态 import ⇒ 直接跳过（`None`）」。实施期实测暴露该规则**过强** ——
> ADD 自身的 `scripts/verify_findings.py` 就含 `__import__`（F-5），导致**真实用例永久不可求值**（T3_30 失败）。
> **精化后的规则**：动态 import 只可能**隐藏边**，因此只威胁**「被禁方向 + 无路径 ⇒ `False`」这一支**：
> - 「允许方向 ⇒ `False`」与图完整性**无关** ⇒ 不受影响；
> - 「被禁方向 + **有**路径 ⇒ `True`」是**正面证据**，不因图不完整而失效 ⇒ 不受影响；
> - 仅「被禁方向 + **无**路径」⇒ 若 `incomplete=True` 则降为 **`None`**，否则 `False`。
>
> 实现上由 `evaluate_contract(..., incomplete=<bool>)` 承载，`verify_contract` 传入 `_has_dynamic_import_at(root, src)`。

### 2.3 `verify_contract` 流程（**None 的判定顺序即 `no-verdict` 优先级**）

```
1. language != "python"                      -> None      # AC-15（复用既有 _detect_language 结果）
2. decls = load_contract_declarations(...)   -> None 若无
3. 对每个 decl（按 rule_id 升序取首个可求值者）:
   3.1 modules = _parse_modules_from_claim(claim)；无/<2   -> 跳过
   3.2 (src,dst) = _parse_direction(claim, modules)；None  -> 跳过
   3.3 graph = _build_graph(repo_root/decl.root)；None（含哨兵） -> 跳过
   3.4 src/dst 不在 graph                                    -> 跳过
   3.5 layer_of(src)/layer_of(dst) 任一为 None               -> 跳过
   3.6 _has_dynamic_import_at(root, src) or (root, dst)      -> 跳过
   3.7 v = evaluate_contract(...)
   3.8 v is None -> 跳过 ; 否则 -> 返回统一 schema (携带 rule_id / kind / src / dst / reason)
4. 全部 decl 均跳过                           -> None      # AC-4：调用方不写 check
```

> 步骤 3.3 的图根：`decl.get("root", ".")`，实际路径 `Path(repo_root) / root`。**若声明未给 `root` 且图触发哨兵 ⇒ `None`**（AC-24）。

**统一返回 schema**

```python
{
  "verified": bool,              # True / False（None 由返回 None 表达，不写进 dict）
  "confirmed": bool,             # 与 verified 同值（既有 dual-field 约定）
  "tier": 2,                     # Tier 2（纯 stdlib）
  "reason": str,                 # 如 "layer_violation_confirmed" / "allowed_direction" / ...
  "kind": "layers",
  "rule_id": str,                # guards 条目的 id（审计追溯锚点）
  "modules": {"src": ..., "dst": ...},
  "path": list[str] | None,      # 命中的实际依赖路径（证据）
  "claim_types": ["contract_related"],
}
```
