## Part A: Phase 2.4a — Python ast CFG (Tier 2) — 先做

### A.0 工程决策

| 决策 | 内容 | 理由 |
|---|---|---|
| **CFG 构建方式** | `ast.NodeVisitor` 单次遍历 | 比 `ast.walk` 多次遍历快 2-3x；单次遍历即可构建完整 CFG |
| **CFG 粒度** | 函数级（模块级代码也构建 CFG，但函数间不连接） | 文件级 CFG 需要跨函数数据流分析，复杂度过高；dead_code claim 基本都是函数内 |
| **可达性算法** | BFS with `collections.deque` | O(V+E) 完备遍历；比 DFS 更适合证明不可达性；deque popleft() 是 O(1) |
| **环检测算法** | 迭代 DFS + 三色标记 (White/Gray/Black) | 递归 DFS 在深层导入链会栈溢出；迭代版安全；三色标记是标准环检测算法 |
| **导入图构建** | `pathlib.Path.rglob("*.py")` + generator | 惰性求值，大项目不一次性加载所有文件；rglob 是 stdlib |
| **AST 异常处理** | `ast.parse` 外层 try/except `SyntaxError` | 语法错误文件降级 Tier 3，不崩溃 |
| **match/case 支持** | `hasattr(ast, 'Match')` 条件检查 | Python 3.10+ 才有 Match 节点；3.8/3.9 需跳过 |
| **async/await 支持** | `AsyncFunctionDef` 与 `FunctionDef` 统一处理 | async 函数的 CFG 结构与同步函数相同 |
| **with 语句处理** | `With` / `AsyncWith` 体作为顺序块 | `with` 的控制流是线性的（__enter__ → body → __exit__），无需特殊分支 |
| **装饰器处理** | 忽略装饰器本身，只处理被装饰函数体 | 装饰器在函数定义前执行，但不影响函数内 CFG |
| **性能上限** | 单文件 5s 超时 | 超时降级 Tier 3 |
| **错误处理** | 所有入口使用 `_script_utils.run_script(main)` | 与现有 28 个脚本一致 |

### A.2 算法效率分析

#### A.2.1 CFG 构建 — `ast.NodeVisitor` 单次遍历

```python
class CFGBuilder(ast.NodeVisitor):
    """O(N) 单次遍历, N = AST 节点数"""

    def __init__(self):
        self.nodes: dict[int, CFGNode] = {}  # line → node
        self.edges: list[tuple[int, int]] = []
        self._current_successors: list[int] = []  # 当前待连接的后继

    def visit_FunctionDef(self, node):
        """函数入口 → 遍历函数体 → 函数出口"""
        # 入口节点
        self._add_node(node.lineno, "FunctionDef")
        self._current_successors = [node.lineno]
        # 遍历函数体
        for stmt in node.body:
            self.visit(stmt)
        # 函数出口: 清空后继 (函数结束)
        self._current_successors = []

    def visit_If(self, node):
        """条件节点 → then 分支 + else 分支 → 合并节点"""
        cond_line = node.lineno
        self._add_node(cond_line, "If")
        self._connect_predecessors(cond_line)

        # then 分支
        then_successors = []
        self._current_successors = [cond_line]
        for stmt in node.body:
            self.visit(stmt)
        then_successors = self._current_successors[:]

        # else 分支
        else_successors = []
        if node.orelse:
            self._current_successors = [cond_line]
            for stmt in node.orelse:
                self.visit(stmt)
            else_successors = self._current_successors[:]
        else:
            else_successors = [cond_line]  # 无 else: 条件节点直连合并

        # 合并: then 和 else 的后继都指向后续语句
        self._current_successors = then_successors + else_successors

    def visit_For(self, node):
        """循环头 → 循环体 → 循环头 (back edge) + 循环出口"""
        loop_line = node.lineno
        self._add_node(loop_line, "For")
        self._connect_predecessors(loop_line)

        # 循环体
        body_successors = []
        self._current_successors = [loop_line]
        for stmt in node.body:
            self.visit(stmt)
        body_successors = self._current_successors[:]

        # back edge: 循环体最后 → 循环头
        for s in body_successors:
            self.edges.append((s, loop_line))

        # 循环出口: 循环头 → 后续语句 (条件不满足时)
        self._current_successors = [loop_line]

    # While 与 For 的 CFG 结构相同 (循环头→体→back edge + 出口→else).
    # else 的触发条件不同 (for: 正常结束; while: 条件 False) 但不影响可达性分析.
    # P2-4: 别名在 CFG 层面正确, dead_code 验证只关心可达性.
    visit_While = visit_For

    def visit_Try(self, node):
        """try 体 + except 分支(s) + else + finally.

        关键不变量: except 分支从 try 入口 (try_line) 连接, 而非 try 体出口.
        理由: try 体内任何点抛异常都应跳到 except, 即使 try 体以 return/raise
        终止 (return 清空 _current_successors, 但不应影响 except 可达性).
        若从 try_successors 连接, try 体有 return 时 try_successors=[] →
        except 无入边 → 误判 except 为 dead code (P1-2 修复).
        """
        try_line = node.lineno
        self._add_node(try_line, "Try")
        self._connect_predecessors(try_line)

        # try 体
        try_successors = []
        self._current_successors = [try_line]
        for stmt in node.body:
            self.visit(stmt)
        try_successors = self._current_successors[:]

        # except 分支: 从 try_line 连接 (非 try_successors)
        # 语义: try 体任何点抛异常 → except; 与 try 体是否 return 无关
        all_branch_exits = try_successors[:]
        for handler in node.handlers:
            handler_line = handler.lineno
            self._add_node(handler_line, "ExceptHandler")
            self.edges.append((try_line, handler_line))  # P1-2 修复: 从 try 入口连接
            self._current_successors = [handler_line]
            for stmt in handler.body:
                self.visit(stmt)
            all_branch_exits.extend(self._current_successors[:])

        # else 分支 (如果 try 无异常): 从 try_successors 连接
        # 语义: try 体正常完成 (无异常) → else; try 体 return 时 else 不可达 (正确)
        if node.orelse:
            self._current_successors = try_successors[:]
            for stmt in node.orelse:
                self.visit(stmt)
            all_branch_exits.extend(self._current_successors[:])

        # finally 分支: 从 all_branch_exits 连接
        if node.finalbody:
            finally_line = node.finalbody[0].lineno
            self._add_node(finally_line, "Finally")
            for s in all_branch_exits:
                self.edges.append((s, finally_line))
            self._current_successors = [finally_line]
            for stmt in node.finalbody:
                self.visit(stmt)

        self._current_successors = all_branch_exits

    def visit_Return(self, node):
        """终止节点: 后续语句不可达"""
        self._add_node(node.lineno, "Return")
        self._connect_predecessors(node.lineno)
        self._current_successors = []  # 清空: 后续不可达

    visit_Raise = visit_Return  # Raise 也是终止节点

    # match/case (Python 3.10+)
    def visit_Match(self, node):
        """match/case: 匹配节点 → 多个 case 分支 → 合并"""
        match_line = node.lineno
        self._add_node(match_line, "Match")
        self._connect_predecessors(match_line)

        all_case_exits = []
        for case in node.cases:
            self._current_successors = [match_line]
            for stmt in case.body:
                self.visit(stmt)
            all_case_exits.extend(self._current_successors[:])

        self._current_successors = all_case_exits

    def generic_visit(self, node):
        """其他语句: 顺序连接"""
        if hasattr(node, 'lineno'):
            self._add_node(node.lineno, type(node).__name__)
            self._connect_predecessors(node.lineno)
            self._current_successors = [node.lineno]
        super().generic_visit(node)
```

**效率要点**:
- 单次遍历: `ast.NodeVisitor.visit()` 对每个节点只调用一次 → O(N)
- 边列表追加: `self.edges.append()` 均摊 O(1)
- 无递归深度问题: `ast.NodeVisitor` 使用栈式遍历

#### A.2.2 可达性 BFS — `collections.deque`

```python
from collections import deque

def is_reachable(cfg_nodes, cfg_edges, entry_line, target_line):
    """BFS 检查 target_line 是否从 entry_line 可达. O(V+E).

    用 deque 而非 list: deque.popleft() 是 O(1), list.pop(0) 是 O(N).
    """
    if entry_line == target_line:
        return True
    if target_line not in cfg_nodes:
        return False

    # 构建邻接表 (一次性, O(E))
    adjacency: dict[int, list[int]] = {n: [] for n in cfg_nodes}
    for src, dst in cfg_edges:
        if src in adjacency:
            adjacency[src].append(dst)

    # BFS (O(V+E))
    visited: set[int] = {entry_line}
    queue: deque[int] = deque([entry_line])

    while queue:
        current = queue.popleft()  # O(1)
        for neighbor in adjacency.get(current, []):
            if neighbor == target_line:
                return True
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)

    return False
```

**效率要点**:
- `deque.popleft()`: O(1)，避免 `list.pop(0)` 的 O(N) 元素移动
- 邻接表构建: 一次性 O(E)，而非每次查询都扫描边列表
- `visited` set: O(1) 查找，避免重复访问

#### A.2.3 导入图环检测 — 迭代三色 DFS

```python
def detect_cycle(graph: dict[str, list[str]]) -> list[str] | None:
    """迭代三色 DFS 环检测. 返回环路径或 None.

    三色标记:
      White (0): 未访问
      Gray (1):  正在访问 (在当前 DFS 路径上)
      Black (2): 已完成 (所有后继已探索)

    迭代版避免递归栈溢出 (深层导入链可能 >1000 层).
    """
    WHITE, GRAY, BLACK = 0, 1, 2
    color: dict[str, int] = {n: WHITE for n in graph}
    parent: dict[str, str | None] = {n: None for n in graph}

    for start_node in graph:
        if color[start_node] != WHITE:
            continue

        # 迭代 DFS
        stack: list[tuple[str, int]] = [(start_node, 0)]  # (node, child_index)
        color[start_node] = GRAY

        while stack:
            node, idx = stack[-1]
            neighbors = graph.get(node, [])

            if idx < len(neighbors):
                stack[-1] = (node, idx + 1)
                neighbor = neighbors[idx]

                if color.get(neighbor, WHITE) == GRAY:
                    # 找到环! 回溯路径
                    cycle = [neighbor]
                    current = node
                    while current != neighbor and current is not None:
                        cycle.append(current)
                        current = parent.get(current)
                    cycle.append(neighbor)
                    cycle.reverse()
                    return cycle

                if color.get(neighbor, WHITE) == WHITE:
                    color[neighbor] = GRAY
                    parent[neighbor] = node
                    stack.append((neighbor, 0))
            else:
                color[node] = BLACK
                stack.pop()

    return None
```

**效率要点**:
- 迭代 DFS: 无递归，不栈溢出
- 三色标记: O(V+E)，每个节点最多访问一次
- 环路径回溯: parent 指针链，O(cycle_length)
- 提前终止: 发现环立即返回，不继续搜索

#### A.2.4 导入图构建 — generator + 批量解析

```python
def build_import_graph(repo_root: str) -> dict[str, list[str]]:
    """扫描项目所有 .py 文件，构建导入图. O(F × S), F=文件数, S=平均文件大小.

    用 rglob + generator 惰性遍历, 不一次性加载所有文件到内存.
    """
    repo = Path(repo_root)
    graph: dict[str, list[str]] = {}

    # 惰性遍历: rglob 返回 generator
    py_files = (f for f in repo.rglob("*.py")
                if "__pycache__" not in f.parts and ".venv" not in f.parts)

    for py_file in py_files:
        # 模块名: 相对路径 → 模块路径 (a/b/c.py → a.b.c)
        try:
            rel = py_file.relative_to(repo)
            module = str(rel.with_suffix("")).replace(os.sep, ".")
        except ValueError:
            continue  # 文件不在 repo 内

        if module not in graph:
            graph[module] = []

        # 解析 import 语句: 只读文件头 (前 100 行通常包含所有 import)
        try:
            content = py_file.read_text(encoding="utf-8", errors="replace")
            tree = ast.parse(content, filename=str(py_file))
        except SyntaxError:
            continue  # 语法错误文件跳过

        # 提取 import (ast.walk 单文件内 O(S), S=文件大小)
        for node in ast.walk(tree):
            if isinstance(node, ast.Import):
                for alias in node.names:
                    target = _resolve_module(alias.name, repo, py_file)
                    if target and target not in graph[module]:
                        graph[module].append(target)
            elif isinstance(node, ast.ImportFrom):
                if node.module:
                    target = _resolve_module(node.module, repo, py_file)
                    if target and target not in graph[module]:
                        graph[module].append(target)

    return graph


def _resolve_module(import_name: str, repo: Path, current_file: Path) -> str | None:
    """将 import 名称解析为项目内模块名. 外部依赖返回 None."""
    # 尝试: import_name → import_name.py 存在?
    candidate = repo / (import_name.replace(".", os.sep) + ".py")
    if candidate.exists():
        return import_name
    # 尝试: import_name → import_name/__init__.py 存在?
    candidate_init = repo / import_name.replace(".", os.sep) / "__init__.py"
    if candidate_init.exists():
        return import_name
    # 外部依赖 (如 numpy, re, os)
    return None
```

**效率要点**:
- `rglob` generator: 惰性遍历，不一次性加载文件列表
- `__pycache__` / `.venv` 过滤: 避免扫描虚拟环境和缓存
- `_resolve_module`: 只解析项目内模块，外部依赖（numpy/re/os）返回 None 不入图
- `ast.walk` 单文件: O(S)，S=文件大小，每个文件独立解析

def verify_dead_code_in_source(code: str, line: int) -> dict:
    """验证给定行号是否是 dead code (不可达).

    Returns:
        {"verified": True|False|None, "evidence": str, "tier": 2, "latency_ms": int}
    """
    start = time.perf_counter()

    # 边界: 空文件
    if not code.strip():
        return {"verified": None, "reason": "empty_file", "tier": 2,
                "latency_ms": int((time.perf_counter() - start) * 1000)}

    # 解析 AST
    try:
        tree = ast.parse(code)
    except SyntaxError as e:
        return {"verified": None, "reason": f"syntax_error: {e.msg}", "tier": 2,
                "latency_ms": int((time.perf_counter() - start) * 1000)}

    # 构建 CFG
    builder = CFGBuilder()
    builder.visit(tree)

    # 找到包含 line 的函数
    func_entry = builder.find_function_entry(line)
    if func_entry is None:
        # 行号不在任何函数内 → 无法判定
        return {"verified": None, "reason": "line_not_in_function", "tier": 2,
                "latency_ms": int((time.perf_counter() - start) * 1000)}

    # BFS 可达性检查
    reachable = is_reachable(builder.nodes, builder.edges, func_entry, line)
    latency = int((time.perf_counter() - start) * 1000)

    return {
        "verified": not reachable,  # 不可达 → dead code → True
        "evidence": f"ast CFG: line {line} {'unreachable' if not reachable else 'reachable'} from entry {func_entry}",
        "tier": 2,
        "latency_ms": latency
    }

    code = abs_path.read_text(encoding="utf-8", errors="replace")

def verify_l4_structural(lines, line_num, claim, claim_types,
                         repo_root=None, file_path=None):
    """Level 4: Structural claim verification with Tier 2 fallback.

    Tier 2 (ast CFG) for dead_code/import_related.
    Tier 3 (regex) for missing/wrong/violates/generic + Tier 2 fallback.

    P0-2 统一 schema: 所有 Tier 结果包含 "verified" 字段 (True|False|None).
    Tier 3 (正则) 原返回 "confirmed", 需映射到 "verified" 保持一致.
    """
    context_start = max(0, line_num - 25)
    context_end = min(len(lines), line_num + 25)
    context_lines = lines[context_start:context_end]
    context_text = "\n".join(context_lines)

    checks = {}

    if "dead_code" in claim_types:
        result = None
        # Tier 2: Python ast CFG
        if repo_root and file_path:
            try:
                import ast_cfg
                result = ast_cfg.verify_dead_code(repo_root, file_path, line_num)
            except Exception:
                result = None
        # Tier 3: 正则 fallback
        if not result or result.get("verified") is None:
            regex_result = _verify_dead_code(context_text, lines, line_num)
            regex_result["tier"] = 3
            regex_result["verified"] = regex_result["confirmed"]  # P0-2: 字段对齐
            checks["dead_code"] = regex_result
        else:
            checks["dead_code"] = result

    if "import_related" in claim_types:
        result = None
        # Tier 2: Python ast 导入图
        if repo_root:
            try:
                import ast_cfg
                result = ast_cfg.verify_imports(repo_root, claim)
            except Exception:
                result = None
        # Tier 3: 正则 fallback
        if not result or result.get("verified") is None:
            regex_result = _verify_import(claim, context_text, lines, line_num)
            regex_result["tier"] = 3
            regex_result["verified"] = regex_result["confirmed"]  # P0-2: 字段对齐
            checks["import_related"] = regex_result
        else:
            checks["import_related"] = result

    # missing/wrong/violates/generic 保持不变 (Tier 3 正则)
    if "missing" in claim_types:
        checks["missing"] = _verify_missing(claim, context_text, lines, line_num)
        checks["missing"]["tier"] = 3
        checks["missing"]["verified"] = checks["missing"]["confirmed"]  # P0-2
    if "wrong" in claim_types:
        checks["wrong"] = _verify_wrong(claim, context_text)
        checks["wrong"]["tier"] = 3
        checks["wrong"]["verified"] = checks["wrong"]["confirmed"]  # P0-2
    if "violates" in claim_types:
        checks["violates"] = _verify_violates(claim, context_text)
        checks["violates"]["tier"] = 3
        checks["violates"]["verified"] = checks["violates"]["confirmed"]  # P0-2
    if "generic" in claim_types and not checks:
        checks["generic"] = _verify_generic(claim, context_text)
        checks["generic"]["tier"] = 3
        checks["generic"]["verified"] = checks["generic"]["confirmed"]  # P0-2

    all_checks = [v for v in checks.values() if isinstance(v, dict)]
    if not all_checks:
        return {"level": 3, "confirmed": False, "verified": False,  # P0-2: 双字段
                "reason": "no_structural_checks_applicable",
                "claim_types": claim_types}

    # P0-2: 优先用 "verified", 回退到 "confirmed" (向后兼容)
    verified = all(c.get("verified", c.get("confirmed", False)) for c in all_checks)
    return {"level": 4 if verified else 3, "confirmed": verified, "verified": verified,
            "claim_types": claim_types, "checks": checks,

## Part B: Phase 2.4b — Joern CPG (Tier 1) — 后做

### B.0 工程决策

| 决策 | 内容 | 理由 |
|---|---|---|
| **Joern 调用方式** | `subprocess.run(["joern-parse", ...])` + `subprocess.run(["joern", "--script", ...])` | 隔离 Joern JVM 进程，崩溃不影响 ADD |
| **CPG 缓存** | `hashlib.sha256(repo_path + content_hash)` | 非 git 项目也能用；content_hash = 所有 .py 文件 mtime 的 hash |
| **Scala 查询脚本** | 动态生成 `.sc` 文件 → `joern --script` | 避免预编译 Joern 项目；脚本动态注入参数 |
| **超时** | 30s (`subprocess.run(timeout=30)`) | 超时降级 Tier 2 |
| **Joern 可用性检测** | `shutil.which("joern-parse")` (Unix) 或 `wsl -d Ubuntu-24.04 -- which joern-parse` (Windows) | O(1) 检测，不启动 JVM |
| **输出解析** | 正则解析 Joern stdout 的 `key=value` 格式 | 简单可靠，不依赖 Joern JSON 输出格式 |
| **Windows 兼容** | Windows 必须通过 WSL2 调用 Joern | Joern v4.0.595 实测: .bat 包装不完整, Python 前端 (pysrc2cpg) 无 .bat 版本; WSL2 是唯一可行路径 |
| **Python 前端语言参数** | `--language pythonsrc` (调用 pysrc2cpg) | 实测 `--language python` 调用旧 `py2cpg.sh`, v4.0.595 中不存在 |
| **dead_code 查询 API** | `cpg.method.lineNumber(N).flatMap(_.caller.l).isEmpty` | P1-5 实测: `location.line(N)` 不存在; `reachableBy` 是数据流 API 不是调用图 API |
| **import_related 查询 API** | `cpg.imports.l` + `imp.importedEntity` + `imp.file.head.name` | P1-5 实测: `imp.imported` 不存在; `imp.importedEntity` 返回 `Option[String]` |

### B.3 CPG 缓存效率分析

```python
def _get_cache_key(repo_root: str) -> str:
    """生成缓存键: repo_path + 文件内容 hash.

    用 mtime 而非文件内容: mtime 读取 O(1), 文件内容读取 O(S).
    """
    repo = Path(repo_root)
    # 惰性遍历: 只取 .py 文件的 mtime
    mtimes = [(str(f.relative_to(repo)), f.stat().st_mtime)
              for f in repo.rglob("*.py")
              if "__pycache__" not in f.parts]
    # 排序确保顺序一致
    mtimes.sort()
    content_hash = hashlib.sha256(str(mtimes).encode()).hexdigest()[:16]
    return f"{hashlib.sha256(repo_root.encode()).hexdigest()[:8]}_{content_hash}"
```

**效率要点**:
- mtime 读取: O(1) per file (stat 系统调用)
- 不读文件内容: 避免 O(S) I/O
- 16 字符 hash: 碰撞概率 ~2^-64，可忽略
